🟡 When to use Uncertain?

Use the Uncertain option

if there is not enough information to determine whether it is a Negative Citation or Non-negative Citation.


Please see the following common cases when to use uncertain:
Common cases when to use Uncertain
  • Pure mention without reporting or summarizing the study content: "This paper was already shared in another post yesterday"
  • Vague language/tone: "Another 'groundbreaking' study…"
  • Unclear connection to the paper: "Why doesn't the media report about it?"
  • User-to-User Interaction: "@userABC, why do you think that?"

Step-by-step Decision

To arrive at consistent decisions, always follow these steps:

Check for a 🔴 Negative Citation

If you find any of the negative citation criteria to be met, label the post as a 🔴 Negative Citation.

If you do not, ask yourself:

"Does this post encourage readers to partially or fully question, doubt, or dismiss the conclusions of the referenced study?"

If yes, label the post as a 🔴 Negative Citation.

If no, check for a 🟢 Non-negative Citation

If you find any of the non-negative citation criteria to be met, label the post as a 🟢 Non-negative Citation.

If you do not, label as 🟡 Uncertain

Note: posts might combine praise and criticism, so that both Negative Citation criteria and Non-negative Citation criteria are met. For this task, Negative Citation criteria take precedence if the criticism is used to make readers question the study's conclusions. As a heuristic, ask "If a reader saw only this comment, would they trust the study's conclusions less?"
For example:
🔴 Negative Citation: "Great study, but the sample is too small to really trust these results."
🟢 Non-negative Citation: "Great study! Although sample is quite small, it provides a crucial proof-of-concept."
